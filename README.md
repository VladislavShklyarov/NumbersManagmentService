### Numbers Managment Service

Проект представляет собой сервис для работы с телефонными номерами.<br>
Проект написан на Go с использованием фреймворка Fiber. Архитектура выстроена по принципам Clean Arcitecture.
Поддерживается работа как с локальным хранилищем (map) так и с PostgreSQL, настраивается параметром "local/postgres" в storage/type файла конфигурации.

### Инфраструктура:

**PostgreSQL** (репликация по принципу master/slave). Поддерживает автоматчиеское перенаправление запросов на чтение на мастера при падении slave-реплики.<br>
**PgAdmin** для мониторинга работы БД

Запуск осуществляется при помощи docker-compose следубщими командами:

```
docker compose down -v
docker compose up --build
```
